Jellyfin integration

Edits the web client's index.html. Re-applied on each server start, so it survives Jellyfin updates.
Replaces Jellyfin's built-in book viewer.

Extra formats

EPUB, PDF and comics (CBZ, CBR, CB7, CBT) work with nothing extra installed. MOBI, AZW3, FB2, DOCX and similar formats are converted to EPUB the first time they're opened, which needs Calibre. DjVu needs DjVuLibre.
